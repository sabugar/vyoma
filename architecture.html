NVIDIA Jetson Orin Nano 8 GB

An ASHA worker presses one button, asks a question in Hindi, and hears an answer grounded in her own training manual — with no SIM, no Wi-Fi and no cloud call. Every figure on these two pages was measured on the device described above.

03Accuracy testing

Answers were being judged one question at a time, which cannot tell an improvement from a trade — a retrieval change that helped scenario questions had already been seen to break factual ones. So correctness is measured, not argued.

A fixed set of ten questions is drawn from the manual. Each carries the fact its answer must contain (2000 for the bathing rule, gauze for the airway step), plus one deliberately out-of-scope question that must be refused. Any change is re-scored in about a minute.

The gap between the two rows is entirely speech and translation noise: when the question reaches the reasoning core intact, the answer is right every time. That is what directed the remaining engineering effort at the input path rather than at the prompt.

The harness found two real defects the eye had missed: a retrieval stemmer under which the question’s weighed could never match the manual’s weigh — making the one page that answers it unreachable — and an over-narrow test assertion that had been failing a correct answer.

Memory is the binding constraint on this board, and power follows it. Steady state is 4.2 GB of 7.4 GB — OS 1715 MB, language model 921 MB, speech and translation service 1593 MB — leaving headroom that stays flat across sustained use: 60 consecutive queries moved swap by 3 MB.

06Engineering quality & code

How the work is structured

  • Two repositories, 23 reviewed commits, each recording the measurement that motivated it — a later reader can tell why a constant is 3.5 and not 2.0.
  • Four systemd units in dependency order. Load order matters: the language model must claim GPU memory before the speech service, or it silently splits across CPU and runs many times slower.
  • Every model runs from local disk. The device is airplane-mode capable by construction, not by configuration.
  • Superseded models are kept in place so a voice or checkpoint can be rolled back without a re-download.

Failures designed for

  • Recording is ended explicitly. The trigger pin cannot report a sustained press — it drops after 7.8 s while the button is still held — so hold-to-talk was cutting questions mid-sentence, losing a नहीं and inverting the answer with it. One press now starts the recording and the next ends it, with a 3.5 s silence timeout as fallback.
  • Empty or unintelligible speech is answered with a spoken Hindi prompt to repeat, never with a guess.
  • Every stage that calls another service retries and reports, so one slow subsystem cannot wedge the interaction loop.
  • Freed memory is returned to the OS after each interaction; on a board with no spare RAM, “free it later” is the same as leaking it.
